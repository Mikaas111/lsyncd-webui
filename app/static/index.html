Folders to sync

Unsaved changes

Tick the folders that must be on the backup. A ticked folder includes everything inside it. Per folder, choose Live (every change reaches the backup within seconds), Scheduled (copied every few hours: for folders that change all the time, such as appdata, so they do not keep sending in between) or Two-way (changes on either server are copied to the other). Removing a folder here stops syncing it; its copy on the backup stays.

Two-way needs write access on the main server. Map the host's /mnt to /mnt-rw (read-write) in this container's settings first.

    Measures each link between the servers on its own, so you can see what limits the sync: the network, SSH encryption or the disks of the backup server.
